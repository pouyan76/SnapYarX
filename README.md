# اسنپ‌یار X

نسخه آغازین اندروید با Kotlin و Jetpack Compose.

## امکانات نسخه آغازین
- تغییر حالت راننده و مسافر
- ثبت درآمد و هزینه برای راننده
- ثبت هزینه سفر برای مسافر
- محاسبه سود خالص بر اساس داده‌های ثبت‌شده
- تاریخچه و گزارش ساده
- ذخیره محلی با SharedPreferences

## ساخت APK
پروژه را در Android Studio باز کنید و از مسیر Build > Build Bundle(s) / APK(s) > Build APK(s) خروجی بگیرید.

همچنین Workflow گیت‌هاب در `.github/workflows/build-apk.yml` برای ساخت APK آزمایشی قرار داده شده است.

## نکته
این برنامه مستقل است و به سامانه داخلی اسنپ متصل نیست. اطلاعات باید دستی وارد شوند. این نسخه اولیه است و هنوز نسخه امضاشده برای انتشار فروشگاهی نیست.
